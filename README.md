# homepage_tachikawa — M2D Lab RPG

ホームページコンペ応募作（立川）。トップページを **2D RPG のゲーム画面**として作り、
伊都キャンパス ウエスト4号館 4F（428 教員室・414 実験室・401 学生居室）を歩いて研究室を知る構成。

- 操作: 矢印キー / WASD で移動、Z / Enter で決定（調べる・話す）、X / Esc / M でメニュー。スマートフォンは画面下の仮想ボタン。
- 会話や掲示物の文章は `src/content/` の YAML / Markdown から自動で取り込む（更新は雛形と同じ手順）。
- 通常の文章ページ（研究室概要・業績など）はメニューから開ける。検索エンジン向けにも残している。

## ゲーム部分の構成（`public/game/`）

| ファイル | 内容 |
|---|---|
| `main.js` | ゲーム本体（入力、移動、会話ウィンドウ、メニュー、描画、フェード） |
| `maps.js` | マップ（文字 1 つ = 1 タイル）。間取りはここを書き換える |
| `tiles.js` | 床・壁・机・装置などのタイル描画（コードで描画。画像差し替え可） |
| `sprites.js` | キャラクターのドット絵（文字で定義）とパレット |
| `game.css` | canvas の拡大表示、仮想ボタン、CRT 風フィルタ |

内部解像度 320×180 を整数倍に拡大して表示し、ドットが滲まないようにしている。外部ライブラリは使っていない。
